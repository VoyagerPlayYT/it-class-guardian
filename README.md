Автономная программная платформа для компьютерных классов информатики, лабораторий и учебных аудиторий. Защищает рабочие станции от несанкционированного изменения системных настроек, блокирует запуск сторонних игр и торрентов, предотвращает переполнение диска `C:` и позволяет преподавателю в 1 клик откатывать весь класс к чистому эталонному состоянию после каждого урока.

---

## Проблема и Решение

В компьютерных классах ученики часто:
- Скачивают сторонние игры (Roblox, Steam, Minecraft, Torrent) и засоряют диск `C:`.
- Меняют системные настройки Windows, фон рабочего стола, удаляют ярлыки нужных программ.
- Пытаются закрыть агент мониторинга через Диспетчер задач или перезагружают компьютер.

**IT-Class Guardian решает эти проблемы:**
1. **Эталонный снимок (Golden Baseline Snapshot):** Преподаватель фиксирует идеальное состояние рабочего стола, документов, ярлыков и настроек.
2. **Откат в 1 клик после каждого урока (Rollback Engine):**
   - Принудительно завершает все несанкционированные процессы.
   - Сравнивает файлы Рабочего стола и Документов с эталоном и автоматически удаляет все новые/лишние файлы, созданные учеником.
   - Очищает папки `Downloads` и `%TEMP%`, освобождая дисковое пространство.
   - Восстанавливает исходные обои и очищает автозагрузку Windows.
3. **Защита от отключения учеником (Tamper Protection & Watchdog):**
   - Запуск через планировщик Windows (`SCHTASKS /sc onlogon /rl highest`) и ветку реестра `HKCU\Run`. Перезагрузка ПК не отключает защиту.
   - Защита от закрытия: закрытие агента или снятие блокировки экрана требует мастер-пароля преподавателя.
4. **Блокировка экрана «Внимание на доску» (Classroom Lock):**
   - Полноэкранный непрозрачный оверлей с блокировкой горячих клавиш переключения окон для концентрации внимания класса на объяснении материала.
5. **Раздача учебных материалов:**
   - Преподаватель загружает файл через панель, и он мгновенно появляется на Рабочих столах всех учеников в папке `Задания_Учителя`.
6. **Живой скриншот экрана (Live Screen View):**
   - Просмотр экрана любого ученика в реальном времени прямо в браузере преподавателя без необходимости подходить к парте.

## Автономная сборка .EXE (Без Python на ПК учеников)

Система собирается в три автономных исполняемых файла:
1. `Учитель_Панель.exe` — консоль сервера с автоматическим запуском и открытием браузера на ПК учителя.
2. `Агент_Ученика.exe` — защитный агент для рабочих станций учеников.
3. `Установщик_Классный_Страж.exe` — графический установщик в 1 клик, настраивающий автозапуск, службы и снимок.

Для компиляции запустите:
```cmd
python build_exe.py
```
Готовые `.exe` появятся в каталоге `dist/`.

## Быстрый запуск

### Запуск Пульта Учителя:
Дважды кликните по скрипту `start.bat`:
```cmd
start.bat
```
Сервер запустится на `http://localhost:8023` и автоматически откроет панель управления в браузере.

### Запуск Тестового Агента Ученика:
Дважды кликните по скрипту `start_agent.bat`:
```cmd
start_agent.bat
```
Агент подключится к серверу учителя, передаст телеметрию и сразу появится на интерактивной карте класса.

## Стек технологий

- **Сервер Учителя:** Python 3.13, FastAPI, Uvicorn, SQLite, WebSockets.
- **Интерфейс:** Чистый HTML5 / CSS3 / ES6 (Linear / Raycast Dark Matte UI, `#0D0D0F`, без тяжелых внешних библиотек).
- **Агент Ученика:** Windows API (`ctypes.windll.user32`), `winreg`, `psutil`, `Pillow` (ImageGrab), `Tkinter` (Lock Overlay).
- **Сборка:** PyInstaller (`--onefile`, `--windowed`, `--uac-admin`).
